# 双击选词的分词与递进选择

- 首次记录：2026-11-16
- 适用场景：以逐列单元格渲染文本、需要鼠标选词的界面（终端类界面、代码编辑器、日志查看器、数据表格）
- 关键词：双击选词、分词、宽字符、单词边界、多击状态机、嵌套选择
- 解决什么问题：双击一次选中"有意义的单元"，并在三击起沿引号/括号与路径结构逐级扩大选区
- 前置知识：无。本文自带完整规则、示例与实现思路，不需要了解任何具体项目

## 1. 问题与目标

固定按空白切词不够用：连续中文应整块选中，路径、URL、版本号、`foo_bar` 这类可整体复制的内容不能被拆碎，而嵌套的引号/括号内容又需要"一次比一次大"的分级选择。目标：

1. 双击任意位置，第一次就选中符合直觉的单元（不是半截）。
2. 后续每多点一次，选区只扩大一级，可预期、可回退（重新双击即复位）。
3. 无词典、无网络、无后台索引；每次点击即时计算，单次开销与可见列数成正比。
4. 中文是常见场景：连续 CJK 必须整块，不能被拆成单字。

## 2. 规则定义

### 2.1 字符分类

| 类别 | 成员 | 参与词的方式 |
|---|---|---|
| 空白 | 空格、Tab、全角空格 | 永远断开 |
| 单词 | 拉丁字母、数字、下划线、非 CJK 的 Unicode 字母/数字 | 词的基本单位 |
| CJK | 汉字、假名、谚文 | 连续块算一个词 |
| 连接符 | `-`、`@`、`#`、`?`、`&`、`=` | 仅两侧都是单词时粘连 |
| 点号 | `.` | 仅两侧都是数字时粘连（版本号、IP） |
| 冒号 | `:` | 三态，见 2.2 |
| 路径分隔符 | `/`、`\`，以及后跟斜杠的冒号 | 断词，但可经路径阶梯整体选中 |
| 引号 | `'`、`"`、`` ` `` | 断词，参与容器阶梯 |
| 其他符号 | 剩余所有字符 | 单独成 token，不参与粘连 |

### 2.2 判定矩阵（按优先级从上到下）

| 输入情形 | 结果 | 理由 |
|---|---|---|
| 宽字符后的空占位列（见 2.4） | 属于前一个宽字符 | 宽字符占两列，第二列是占位 |
| 冒号（或连续冒号）两侧是十六进制位 | 粘连（时间 `18:30`、IPv6 `fe80::1`、MAC、`host:port`） | 这些是不可分割单元，粘连优先于断开 |
| 冒号后紧跟 `/` 或 `\` | 路径分隔符（盘符 `C:\`、URL scheme `https://`） | 冒号在此是路径语法的一部分 |
| 其余冒号（`error:`、`key:value`、空格后） | 断开 | 分隔符语义，且冒号不该混进词尾 |
| 点号两侧都是数字 | 粘连（`v1.2.3`、`127.0.0.1`） | 版本号、IP、小数是整体 |
| 其余点号（字母之间、句末） | 断开（`changelog` 与 `md` 分开） | 文件名扩展留在路径阶梯里扩展，句点不吞词 |
| 连接符两侧都是单词字符 | 粘连（`foo-bar`、`user@host`、`a=1&b=2`） | 代码标识符整体复制 |
| 连接符任一侧是空白/符号 | 断开（`--flag` 双击选中 `flag`，`ls -la` 选中 `la`） | 脱离词的前缀不属于词 |
| 斜杠/反斜杠 | 永不并入词（`docs/atlas` 双击选中 `docs` 或 `atlas`） | 路径段可独立复制，整条走路径阶梯 |
| 连续 CJK 块 | 整块一个词；与拉丁字母交界断开（`中文abc` 断开） | 中文整块，避免散文粘连 |
| 其余 | 空白断开，符号单独成 token | 兜底 |

### 2.3 多击状态机

| 击数 | 层级 | 选区 |
|---|---|---|
| 1 | 字符 | 单击不选中；作为拖拽起点 |
| 2 | 词 | 双击位置所在的词（规则见 2.2） |
| 3 及以上 | 阶梯第 `击数-2` 步 | 先走容器阶梯，无容器走路径阶梯，都耗尽则整行 |
| 拖拽 | 保持当前层级 | 以当前层级为单位向拖拽方向扩展 |

判定：500ms 内、同一行、列差不超过 1 记为连击；位置或间隔超限则重新从 1 计。双击位置是锚点，后续击不移动锚点。

**容器阶梯**（引号、括号 `() [] {}` 及全角对应）：

| 阶梯步 | 选区 | 说明 |
|---|---|---|
| 奇数步（1、3、5…） | 第 `(步+1)/2` 层容器的**内部** | 由内向外逐层 |
| 偶数步（2、4、6…） | 同层容器**含定界符** | 如 `'tom cat 1'` |
| 超出层数 | 交给路径阶梯；路径也耗尽则整行 | 封顶 |

引号开合判定：引号前一个字符是单词字符时视为撇号，不开启容器（`don't` 不会被选成 `'t` 容器）。括号配对时跳过引号内部（`("a (b)")` 里的内层括号不参与）。

**路径阶梯**（斜杠分隔的结构）：

| 阶梯步 | 选区 | 说明 |
|---|---|---|
| 1 | 词的**路径段**（`changelog` → `changelog.md`）；段等于词时直接给整条路径（`atlas` → `docs/atlas/changelog.md`） | 段内有可扩展内容才扩展 |
| 2 | 整条路径（`docs/atlas/changelog.md`、`C:\Users\demo\project`、`https://example.com/a?b=1`） | 仅当第 1 步给过段 |
| 超出 | 整行 | 封顶 |

路径结构判定：段 = 分隔符之间的一段字符（可含连接符、点号、紧邻分隔符的 `~`、后跟十六进制位的 `%`）；CJK 与拉丁字母交界处段被切断（中文散文不会粘进路径）；结构两端悬空的分隔符（行首 `/`、行尾 `/`）计入路径。

### 2.4 宽字符列占位（最容易错的一条）

若文本按列存储（每列一个字符串，宽字符占两列），则宽字符的第二列是空串。行尾空白填充也是空串。两者从值上无法区分：

- 把空列一律当空白 → 宽字符被切断，双击中文只选半个字。
- 把空列一律继承前一列 → 行尾空白继承最后一个词的类别，选区延伸到屏幕最右列。

唯一正确判定：**空列只在"前一列是宽字符"时属于前一个字符，否则是空白填充**。宽字符判定用码点表（CJK、全角形式、常用 emoji 区段）。

### 2.5 超出三击后的行为是产品决策

三击之后有两种可选方案，实现前必须定死一种：

- **整行封顶（推荐）**：可预期，用户不会误选多行；全选走快捷键。
- 每次上下各扩一行直到全选：学习成本高，且与"双击复位"的直觉冲突。

## 3. 实现思路

数据结构：`cells: string[]`（定长列数）→ 逐列分类 `classes` → 词 token 列表；容器链与路径结构在需要时按行计算。

处理顺序：分类（含宽字符占位继承）→ 连接符/冒号/点号的二次归并 → 词 token 合并 → 多击层级解析。

```ts
type CellClass = "space" | "word" | "cjk" | "glue" | "path" | "quote" | "symbol";

// 第一步：逐列分类。空列只在“前一列是宽字符”时继承，其余是行尾空白。
function classifyColumns(cells: string[], isWide: (cell: string) => boolean): CellClass[] {
  const classes = cells.map((cell) =>
    cell === "" ? "space" : classifyChar(cell.codePointAt(0)!),
  );
  for (let i = 1; i < cells.length; i += 1) {
    if (cells[i] === "" && cells[i - 1] !== "" && isWide(cells[i - 1])) {
      classes[i] = classes[i - 1];
    }
  }
  return classes;
}

// 第二步：连接符与冒号/点号按“连续段 + 两侧字符”二次归并，不要在单字符分类里解决。
// 冒号：十六进制两侧 -> glue；后跟斜杠 -> path；否则保持 symbol。
function resolveRuns(cells: string[], classes: CellClass[], runChar: string) {
  let i = 0;
  while (i < cells.length) {
    if (cells[i] !== runChar) { i += 1; continue; }
    let end = i;
    while (end + 1 < cells.length && cells[end + 1] === runChar) end += 1;
    const before = cells[i - 1] ?? "";
    const after = cells[end + 1] ?? "";
    if (runChar === ":" && hexDigit(before) && hexDigit(after)) {
      for (let k = i; k <= end; k += 1) classes[k] = "glue";
    } else if (runChar === ":" && (after === "/" || after === "\\")) {
      for (let k = i; k <= end; k += 1) classes[k] = "path";
    } else if (runChar === "." && digit(before) && digit(after)) {
      for (let k = i; k <= end; k += 1) classes[k] = "glue";
    }
    i = end + 1;
  }
}

// 第三步：合并词 token。连接符仅当左右都是词时并入。
function tokenize(classes: CellClass[]): Array<{ start: number; end: number; kind: CellClass }> {
  const runs = []; // 同类连续列先成段
  // ... 略：按类别切段
  const tokens = [];
  for (let i = 0; i < runs.length; i += 1) {
    const run = runs[i];
    const next = runs[i + 1];
    if (run.kind === "glue" && tokens.length > 0 && next?.kind === "word"
        && tokens[tokens.length - 1].kind === "word") {
      tokens[tokens.length - 1].end = next.end; // 词-连接符-词 合成一个
      i += 1;
      continue;
    }
    tokens.push(run);
  }
  return tokens;
}

// 第四步：多击层级解析。阶梯统一为“每击走一步”，新增结构只需新增一个 rangeAt。
function resolveLevel(clicks: number, anchor: Point, line: Line): Level {
  if (clicks <= 1) return { mode: "char" };
  if (clicks === 2) return { mode: "word", range: wordTokenAt(line, anchor) };
  const step = clicks - 2;
  const container = containerRangeAt(line, anchor, step); // 内部/含定界符交替，逐层外扩
  if (container) return { mode: "container", step, range: container };
  const path = pathRangeAt(line, anchor, step);           // 段 -> 整条
  if (path) return { mode: "path", step, range: path };
  return { mode: "line", range: wholeLine(line) };
}
```

容器阶梯的步进映射：容器链按由内向外排序，第 `k = (step-1)/2` 层，奇数步取内部、偶数步含定界符。路径阶梯的步进映射：第 1 步段不等于词则给段，否则给整条；第 2 步仅在段不等于词时给整条；其余返回空。

## 5. 为什么有效

规则层是纯函数：分类、归并、token 化都不依赖界面框架，可以脱离任何运行时单测；交互层只维护"击数 + 锚点"，每次向规则层要一个区间，错一次不影响状态。阶梯模型把任意嵌套结构（引号、括号、路径）的选择统一成"每击一步"，新增一类结构只需再写一个 `xxxRangeAt(step)` 并入查询链，既有阶梯零改动。

前提：文本已按固定列（或字符偏移）切成可随机访问的单元。若选词需要"语义分词"（中文词性、代码 AST），纯规则不够，需要词典或语法树；若选择要跨行（多行字符串、块结构），需要额外的行间扫描。

## 6. 常见误区

| 误区 | 后果 | 正确做法 |
|---|---|---|
| 空列一律当空白 | 中文双击只选半个字 | 按"前一列是否宽字符"判定占位 |
| 空列一律继承前一列 | 词延到屏幕最右列 | 同上，两者必须分开处理 |
| 连接符一律粘连 | `error:`、`--flag` 连前缀一起选中 | 仅两侧都是单词字符时粘连 |
| 点号一律粘连 | `changelog.md` 的第一击变成整段，失去扩展粒度 | 仅数字两侧粘连 |
| 冒号一律断开 | `https://`、`C:\` 碎成多段 | 数字/十六进制两侧或后跟斜杠时特殊处理 |
| 斜杠粘连成长路径 | 路径段无法单独复制 | 斜杠断词，整条走阶梯 |
| 三击后无限扩行 | 误选多行、与双击复位冲突 | 定死"整行封顶"或逐行扩展中的一种 |
| 规则表与示例不一致 | 实现纠结、行为摇摆 | 以具体示例为准，逐条与产品方确认 |

## 7. 迁移到其他产品形态

| 形态 | 不变 | 必须改 |
|---|---|---|
| 纯文本文档（编辑器） | 2.2 全部规则、2.3 击数映射、阶梯模型 | 无单元格与宽字符占位列问题，用字符偏移；引号/括号匹配可用文本扫描或语法树 |
| 日志查看器 | 规则、阶梯 | 虚拟滚动下按可视行计算；长行需要横向裁剪 |
| 数据表格 | 路径/容器规则大多用不上 | 选择单位换成单元格/行；列宽与换行后的显示映射 |
| 是否要整行 | 三击封顶策略 | 编辑器通常三击整行，逻辑行与视觉行的区别 |

改动清单：① 把"列号"换成目标形态的坐标（字符偏移/单元格）；② 宽字符占位列的处理按目标模型取舍；③ 容器匹配来源（文本扫描 vs 语法树）；④ 三击之后的封顶策略与快捷键分工。

## 8. 验证清单

规则层（纯函数，逐条给正例与反例）：

1. 连续 CJK 整块；宽字符的第二列与行尾空白分别双击，结果正确。
2. `中文abc` 交界断开；`foo_bar`、`foo-bar`、`user@host`、`a=1&b=2` 整块。
3. `18:30:00`、`fe80::1`、`127.0.0.1:8080` 整块；`error:`、`key:value` 断开。
4. `v1.2.3` 整块；`changelog.md` 分两段且阶梯可合。
5. 路径：`docs/atlas/changelog.md` 的段/整条；`/usr/local/bin` 行首斜杠计入；`~/bin`、`./scripts/build.ts` 边界；`C:\Users\demo\project` 盘符计入；`https://example.com/a?b=1` scheme 计入。
6. 容器：`'tom cat 1'` 两击序列；`"name:'tom cat 1'"` 六击序列；`don't` 不开启容器；`call("x", [1, 2])` 括号配对跳过引号内部。
7. 阶梯耗尽后回落整行；步数超出返回空（不得抛错）。

交互层：连击窗口边界（间隔 499ms 与 501ms）、位置容差（列差 1 与 2）、双击后拖拽按词扩展、拖出容器/路径后的回退。
