# 关闭窗口与系统托盘

- 最后校验：2026-11-07
- 状态：已覆盖

## 1. 业务需求

用户点右上角关闭按钮（或系统关闭手势）时，不再只有「退出」一种结果：

- 每次弹出选择窗口，让用户选「退出程序」或「缩小到托盘」，勾选「记住我的选择」后下次不再弹窗；
- 用户之后的任何时间都可以在「设置 → 通用 → 窗口 → 关闭窗口时」改为每次询问、直接退出或缩小到托盘；
- 缩小到托盘后，托盘图标左键恢复主窗口，右键菜单提供「打开 Terax」与「关闭程序」；
- 桌面图标、命令行等任何途径再次启动时不产生第二个进程：唤回已运行的窗口，携带的文件参数在原实例打开；
- 未保存的编辑器与仍在运行的终端进程，对「退出程序」仍然先确认。

## 2. 入口与调用链

- 关闭按钮：`src/components/WindowControls.tsx:70` 调用 `getCurrentWindow().close()`，由 Tauri 触发 `onCloseRequested`。
- 关闭守卫：`src/app/hooks/useAppCloseGuard.ts:138` 的 `onCloseRequested`。先 `preventDefault`，再按偏好决定：
  - `closeAction === "tray"` → `hideToTray`（`:108`）
  - `closeAction === "quit"` → `quitWithGuard`（`:117`），保留忙碌终端/脏编辑器确认
  - `closeAction === "ask"` → 打开选择窗口（`pendingCloseChoice`）
- 选择窗口：`src/app/components/CloseDialogs.tsx:203`，两个动作 + 「记住我的选择」；确认后 `onChooseCloseAction(action, remember)` 交给 `src/app/hooks/useAppCloseGuard.ts:175` 的 `chooseCloseAction`。
- 最小化到托盘：`src/app/lib/appTray.ts:10` 的 `minimizeToTray()` 调用原生命令 `tray_show`，成功后 `window.hide()`；托盘创建失败（Linux）则回落为退出。
- 托盘实现：`src-tauri/src/modules/tray.rs:86` 的 `tray_show` / `:95` 的 `tray_hide`；`:30` 创建图标与菜单，`:12` 的 `reveal_main_window` 展示并聚焦主窗口。
- 二次启动：`src-tauri/src/modules/single_instance.rs:12` 封装 `tauri-plugin-single-instance`，在 `src-tauri/src/lib.rs:151` 注册为第一个插件。新进程把 argv 转发给运行中的实例后立即退出；回调先 `reveal_main_window` 唤回窗口，文件参数经 `src-tauri/src/lib.rs:96` 的 `seed_launch_target` 走 macOS「打开方式」同款链路打开。
- macOS Dock：`src-tauri/src/lib.rs:399` 处理 `RunEvent::Reopen`，窗口不可见时同样调用 `reveal_main_window`。
- 退出捷径：终端最后一个 shell 退出时 `src/app/App.tsx:1309` 调用 `quitWithoutChoice()`，跳过选择窗口但仍走忙碌/脏检查。

```text
关闭按钮 / Alt+F4 / macOS 红点
  -> WindowEvent::CloseRequested
  -> useAppCloseGuard.onCloseRequested
  -> closeAction = ask | quit | tray
       ask  -> CloseDialogs 选择窗口 -> chooseCloseAction(remember)
       quit -> 忙碌终端/脏编辑器确认 -> finishClose -> window.close()
       tray -> minimizeToTray -> invoke tray_show -> window.hide()

托盘左键 -> tray.rs reveal_main_window -> window.show + unminimize + set_focus
托盘右键菜单「关闭程序」 -> app.exit(0)

桌面图标/命令行再次启动 -> single_instance 插件转发 argv -> 新进程退出
  -> 原进程回调 reveal_main_window -> seed_launch_target 打开携带的文件
macOS Dock 点击（窗口不可见） -> RunEvent::Reopen -> reveal_main_window
```

## 4. 数据流 / 关键流程

1. 偏好 `closeAction` 默认 `ask`；`loadPreferences` 用 `coerceCloseAction` 归一化未知值（`src/modules/settings/store.ts:556`）。
2. 关闭请求到达后只读取一次偏好快照（`usePreferencesStore.getState()`），避免弹窗期间改设置造成歧义。
3. 选择窗口勾选「记住」时，先把选择写入偏好（`setCloseAction`），再执行动作；写入失败只记录日志，不阻断关闭。
4. 「缩小到托盘」先创建托盘再隐藏窗口，顺序反了会让窗口不可见且无恢复入口；托盘已存在时 `tray_show` 直接返回。
5. 托盘左键与「打开 Terax」都调用 `reveal_main_window`：`show` + `unminimize` + `set_focus`。托盘图标在首次创建后保留到进程结束，重复缩小不会重复创建。
6. 「退出程序」沿用原有流程：先检查终端前台进程与脏编辑器，再 `flushSessionWrites` 落盘，最后 `window.close()`。
7. 终端最后一个 shell 退出属于程序自身的退出决策，`quitWithoutChoice` 只跳过「选择窗口」，不跳过落盘与脏检查。
8. 二次启动转发到达时先恢复窗口再打开文件：窗口此刻可能正藏在托盘；没有文件参数就只恢复。前端尚未启动时，文件先落 drain-once 状态，由启动排水兜底，监听已挂载则直接收 `terax:open-file` 事件。
9. `seed_launch_target` 会顺带把文件父目录写入工作区授权注册表，与 macOS「打开方式」的信任模型一致：用户显式指定打开的文件即视为同意。
10. macOS Dock 点击在没有任何可见窗口时触发 `Reopen`，走与托盘相同的 `reveal_main_window`；有可见窗口时保持系统默认激活行为。

## 5. 对外接口

- 偏好键：terax-settings.json 的 `closeAction`，取值 `ask | quit | tray`，默认 `ask`。
- IPC：`tray_show({ openLabel, quitLabel })`、`tray_hide()`（`src-tauri/src/modules/tray.rs`）。
- i18n：`app.tray.*`、`app.closeChoice.*`、`settings.general.window.closeAction.*`（en/zh 同构）。
- 设置搜索锚点：`general.window.closeAction`。

## 6. 配置与依赖

- Tauri 特性：`tauri = { features = ["tray-icon"] }` 只声明在 `cfg(any(windows, macos))` 的依赖段，Linux 构建不引入 libappindicator。
- 单实例：`tauri-plugin-single-instance = "2"` 同样只声明在 Windows/macOS 目标段。Linux 无托盘（关闭即退出），且插件在 Linux 依赖 D-Bus 会话总线，故不引入。
- 插件以 bundle id（`app.wang.terax`）为单实例标识；注册顺序必须是第一个插件，二次启动才能在任何插件完成初始化前转发并退出（约束见 lore [invariants.md](../../lore/invariants.md) INV-017）。
- 托盘图标取应用默认窗口图标（`app.default_window_icon()`），固定在通知区域以「Terax」为 tooltip。
- 跨平台差异：macOS 是菜单栏图标，Windows 是通知区域图标；Linux 无托盘后端，选择「缩小到托盘」会直接退出。

## 7. 已知限制与注意事项

- Linux 构建没有托盘：`tray_show` 返回错误，前端回落为正常退出，避免窗口隐藏后无法找回。
- 托盘「关闭程序」由 Rust `app.exit(0)` 直接结束进程，不经过网页侧的会话落盘与脏编辑器确认；需要完整收尾时请用窗口关闭按钮（取舍理由见 lore [decisions/2026-11-07-托盘退出直接结束进程.md](../../lore/decisions/2026-11-07-托盘退出直接结束进程.md)）。
- 托盘图标首次出现后不会自动消失（重复缩小只复用），这是为了避免在菜单事件回调里销毁图标。
- 选择「缩小到托盘」不会提示正在运行的进程或未保存的文件，因为应用仍在运行。
- 关闭选择窗口写入偏好的时机在动作之前，若偏好写入很慢，弹窗会短暂停留；写入失败不阻断动作。
- dev 实例与已安装版共享单实例标识：一边运行时启动另一边，会被转发到运行中的那个进程后退出（调试时注意）。
- 二次启动携带的文件参数不弹工作区授权确认（与 macOS「打开方式」一致），父目录直接进入授权注册表。
