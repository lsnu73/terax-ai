## 业务需求

设置页让用户在主窗口内调整通用、编辑器、主题、快捷键、模型、AI 行为、代理和关于信息。顶部搜索框需要跨分区查找设置选项，并在选择结果后把用户带到对应设置位置，而不是要求用户逐个分区查找。

## 入口与调用链

1. 深层组件调用 `src/modules/settings/openSettings.ts:24` 的 `openSettings(section?)`；`src/app/App.tsx:618` 把 `openSettingsTab` 注册为实际打开器。
2. `src/modules/tabs/lib/useTabs.ts:1124` 的 `openSettingsTab` 复用全局单例 settings tab；`setSettingsSection`（同文件 1159 行）同步分区状态。
3. `src/app/components/WorkspaceSurface.tsx:170` 渲染 `SettingsView`。设置 tab 切到后台时仅隐藏，组件保持挂载。
4. `src/settings/SettingsView.tsx:88` 维护当前 `active` 分区；手动切换和搜索跳转都通过 `setActive` 与 `onSectionChange` 同步回 tab 状态。

搜索链路：

`SettingsSearch` 输入查询 → `SETTING_SEARCH_ITEMS` 提供元数据 → 当前语言文案与偏好可见性过滤 → 选择结果 → `SettingsView.onSearchSelect` 切换分区 → 查找 `data-setting-id` → 滚动并短暂高亮。

- 搜索组件：`src/settings/components/SettingsSearch.tsx:18`
- 静态索引：`src/settings/settingsSearch.ts:16`
- 结果选择与定位：`src/settings/SettingsView.tsx:114`、`:155`
- 普通设置行锚点：`src/settings/components/SettingRow.tsx:21`

## 搜索范围与行为

- 匹配当前语言下的选项标题、说明、分组、分区名和额外关键词，忽略大小写；快捷键还复用 `SHORTCUTS` 清单，可搜索具体快捷键名称与稳定 ID。
- 使用现有 `Command` 组件支持上下键、Enter 和 Escape；选择结果后清空查询并关闭浮层。
- 自动换行列、自动保存延迟、格式化子项、补全触发方式及背景图效果等条件选项，只在对应偏好使其可见时出现。
- 通用分区的应用内通知显示方式使用 `general.agents.displayMode` 锚点，可搜索“直接显示消息”或“仅显示未读标记”。
- 搜索结果只读取元数据，不挂载所有分区，也不修改任何设置值。
- 目标分区异步内容尚未挂载时，`MutationObserver` 短暂等待锚点；找不到目标则回到分区顶部。定位尊重减少动态效果偏好。
- 查询与结果浮层是设置页内局部状态，不持久化。快捷键分区原有的列表过滤仍独立存在。

## 对外接口与关联功能

- 分区标识以 `src/modules/settings/openSettings.ts` 的 `SettingsTab` 为准。
- 搜索元数据结构以 `src/settings/settingsSearch.ts` 的 `SettingSearchItem` 为准，无原生 IPC 或网络接口。
- 模型详细编辑见 [AI模型配置](AI模型配置.md)，AI 提示词见 [AI提交信息生成](AI提交信息生成.md)，代理规则见 [代理](代理.md)，更新入口见 [设置-关于](设置-关于.md)。

## 已知限制

- 用户动态创建的模型、Provider、Agent、片段和自定义 LSP 服务器不逐项进入索引，只提供所属区域入口。
- 依赖平台能力或异步探测的 Mica/Vibrancy、WSL 工作区环境目前不在索引中。
- 新增设置项若需可搜索，必须同步登记索引与目标锚点；维护约束见顶部静态索引决策。
