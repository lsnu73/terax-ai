## 业务需求

设置页让用户在主窗口内调整通用、编辑器、主题、快捷键、模型、AI 行为、代理和关于信息。页面采用左侧竖向栏加右侧内容区：左侧第一项是跨分区搜索框，其下排列分区导航；右侧显示当前分区内容。搜索需要跨分区查找设置选项，并在选择结果后把用户带到对应设置位置，而不是要求用户逐个分区查找。设置页激活时，Ctrl/Cmd+F 聚焦左侧导航的搜索框，而不是终端的搜索弹窗。

搜索结果按分区归组。每个分区名称是独立的分组标题行，属于该分区的结果排列在标题下方；结果卡片提供分类竖条、标题栏和结果数量，结果通过左侧引导线与分类关联。搜索浮层宽度不受左侧导航栏宽度限制，最小与输入框同宽，按内容扩展并可完整换行，最大 40rem 且不超过视口。

## 搜索范围与行为

- 匹配当前语言下的选项标题、说明、分组、分区名和额外关键词，忽略大小写；快捷键还复用 `SHORTCUTS` 清单，可搜索具体快捷键名称与稳定 ID。
- 使用现有 `Command` 组件支持上下键、Enter 和 Escape；选择结果后清空查询并关闭浮层。
- 结果按 `item.section` 第一次出现的顺序分组，组内保持索引顺序；同一分区内的结果不重复显示分类。
- 分类标题使用独立标题栏、主色竖条和结果数量；结果项纵向显示标题与说明，并通过左侧引导线归属到分类。
- 结果浮层以输入框为锚点向左对齐，宽度按内容扩展到 40rem 或视口上限；标题和说明允许完整换行，不做单行截断。
- 自动换行列、自动保存延迟、格式化子项、补全触发方式及背景图效果等条件选项，只在对应偏好使其可见时出现。
- 通用分区的应用内通知显示方式使用 `general.agents.displayMode` 锚点，可搜索“直接显示消息”或“仅显示未读标记”。
- 搜索结果只读取元数据，不挂载所有分区，也不修改任何设置值。
- 目标分区异步内容尚未挂载时，`MutationObserver` 短暂等待锚点；找不到目标则回到分区顶部。定位尊重减少动态效果偏好。
- 查询与结果浮层是设置页内局部状态，不持久化。快捷键分区原有的列表过滤仍独立存在。
- Ctrl/Cmd+F 在设置 tab 激活时聚焦左侧搜索框并全选已有查询；其他 tab 仍按 [标签内搜索](标签内搜索.md) 的规则路由，设置页的聚焦函数只在注册后可用。
- 新增可搜索的设置项必须同时更新 `SETTING_SEARCH_ITEMS`、`SettingRow` 的 `searchId` 或 `data-setting-id`，并补齐中英文案；约束见 INV-015。

## 已知限制

- 用户动态创建的模型、Provider、Agent、片段和自定义 LSP 服务器不逐项进入索引，只提供所属区域入口。
- 依赖平台能力或异步探测的 Mica/Vibrancy、WSL 工作区环境目前不在索引中。
- 新增设置项若需可搜索，必须同步登记索引与目标锚点；维护约束见顶部静态索引决策。
- 搜索浮层最大宽度为 40rem 且不超过视口，单条说明仍可能因极长单词或视口过窄而受换行限制；左侧导航固定宽度为 13rem。
- 分类标题与组内结果由 `SettingsSearch` 的局部 `Map` 派生，不进入静态索引，也不提供单独折叠或跳转。
- 设置页从未挂载时没有注册聚焦函数，此时 Ctrl+F 不会产生效果；设置页挂载后一直保持注册，即使 tab 被隐藏。
