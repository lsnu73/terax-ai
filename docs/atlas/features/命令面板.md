# 命令面板

- 最后校验：2026-10-31（`terax-diy`）
- 状态：已上线
- 关联约束：暂无

## 1. 业务需求

提供一个键盘优先的全局命令入口：用户用快捷键或顶栏按钮打开浮层，按名称模糊搜索并执行应用命令、切换主题、在文件中查找文本。搜索框支持两种前缀模式：`#` 进入工作区文本内容搜索，`?` 查看搜索模式帮助。空查询时按最近使用（MRU）排序展示全部命令；「搜索命令历史」模式已于 2026-10-31 移除，终端历史改由 Shell 自身 Ctrl+R 承担。

## 2. 入口与调用链

- 打开入口：
  - 快捷键：`src/app/App.tsx` 的 `commandPalette.open`（默认 Ctrl/Cmd+K）与 `commandPalette.content`（`#` 预填内容搜索）处理器（约 890 行）。
  - 顶栏按钮：`src/modules/header/Header.tsx` 的命令面板按钮。
- 渲染：`src/app/App.tsx` 挂载 `CommandPalette`（约 1589 行），传入 `commandItems`、`workspaceRoot`、`onOpenContentHit`。
- 命令注册：`src/modules/command-palette/commands.ts` 的 `createCommandItems(ctx)` 按分组产出 `PaletteItem[]`，禁用态用 `disabledReasonKey` 表达。
- 查询分流：`src/modules/command-palette/lib/mode.ts` 的 `parseQuery` 按前缀 `#`/`?` 分为 `content`/`help` 模式，无前缀为 `commands`。
- 排序：`src/modules/command-palette/lib/mru.ts` 的 `mruSnapshot`/`recordUse` 记录最近使用；`src/modules/command-palette/lib/fuzzy.ts` 的 `fuzzyBest` 做模糊匹配打分。

```text
打开面板 -> parseQuery(query)
  -> commands 模式: rankCommands(fuzzy + MRU) -> runCommand
  -> content 模式(#): useContentSearch -> onOpenContentHit(path, line)
  -> help 模式(?): 展示 MODE_HINTS
主题子页: theme.pick 进入 page="themes"，悬浮预览 + commit 提交
```

## 4. 数据流与关键流程

1. 面板打开时重置查询；`initialMode === "content"` 时预填 `#`。
2. `commands` 模式下，空查询按 MRU 排序返回全部命令，有查询词则对标题、分组名和 keywords 模糊打分后排序。
3. `theme.pick` 不关闭面板，切到主题子页；悬浮高亮主题项延时 140ms 预览，选中才提交，Esc 或退格回根页并撤销预览。
4. `search.content` 项把查询改写为 `#` 进入内容搜索；命中项经 `onOpenContentHit` 打开文件并跳到指定行。
5. 执行命令时 `recordUse(item.id)` 更新 MRU，随后先关闭面板再延时执行命令本体。

## 5. 对外接口

- `CommandPalette` Props：`open`、`onOpenChange`、`initialMode`、`commandItems`、`workspaceRoot`、`onOpenContentHit`。
- `createCommandItems(ctx): PaletteItem[]`：命令清单的事实来源，新增命令在此登记。
- 无新增 Tauri command 或持久化格式；内容搜索复用 header 模块的搜索 IPC。

## 6. 配置与依赖

- 快捷键事实来源：`src/modules/shortcuts/shortcuts.ts` 的 `commandPalette.open` / `commandPalette.content`。
- UI 组件复用 `src/components/ui/command`（cmdk 封装）与 `ScrollArea`。
- MRU 仅存内存，应用重启后排序重置。

## 7. 已知限制与注意事项

- 面板不过滤非命令模式的回车选择：`shouldFilter=false`，过滤完全由各模式自行完成，新增模式必须自带过滤或空态。
- 历史遗留：`>` 搜索命令历史模式已删除（2026-10-31），`lib/history` 依赖已断开；终端内 Ctrl+R 仍走 Shell 原生反向搜索，与面板无关。

## 8. 变更记录

- 2026-10-31：删除 `>` 搜索命令历史模式：移除 `history.open` 命令项、`useCommandHistory` hook、`insertCommand` 接线、`PaletteMode` 的 `history` 分支及中英文案；命令面板首次登记为已覆盖功能。
