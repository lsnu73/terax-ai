## 业务需求

用户配置本地 HTTP 代理（地址默认 `localhost`，端口默认 `7890`），按场景独立开关：终端、AI 会话、更新；支持全部开启/全部关闭。可配置代理软件路径，开启「自动启动」后，已配置代理且任一场景启用而软件未运行时自动拉起软件。状态栏 AI 按钮左侧的代理按钮提供同样的三场景开关。

## 入口与调用链

- 设置分区：`src/settings/SettingsView.tsx` TABS → `src/settings/sections/ProxySection.tsx`；状态栏：`src/modules/statusbar/StatusBar.tsx` → `src/modules/proxy/components/ProxyStatusButton.tsx`。两者共用 `Preferences.proxy`（`src/modules/settings/store.ts`，`setProxySettings` 持久化到 **terax-settings.json** 并跨窗口广播）。
- URL 解析：`src/modules/proxy/lib/proxy.ts` `resolveProxyUrl` / `proxyForScenario`；地址或端口不合法视为未配置。
- 终端：`src/modules/terminal/ghostty/useGhosttyTerminalSession.ts` → `openPty(..., proxy)` → `pty_open` → `session::spawn` → `shell_init::build_command`；`apply_proxy_env` 注入/清除大小写 `HTTP(S)_PROXY`、`ALL_PROXY`，WSL 由 `wslenv_with_terax` 合并终端集成与代理 token，保留并去重已有 `WSLENV`。仅影响新建 PTY。
- AI：`src/modules/ai/lib/proxyFetch.ts` 每次请求动态读取偏好，metadata 带 `proxy` → `net.rs ai_http_stream` → `clients.rs client_for`；代理地址是 `ClientKey` 的一部分，`None` 时 `no_proxy()` 直连。
- 更新：`useUpdater.runCheck` 读取更新场景代理；非 Linux `check({ proxy })`（随 Update 保留到下载），Linux 走新命令 `net_http_get`（reqwest，遵循同一开关）。
- 自动启动：`src/modules/proxy/lib/autoLaunch.ts`（App 挂载 `useProxyAutoLaunch`，启动时与 proxy 偏好变更时触发）→ `proxy_ensure_running`（`src-tauri/src/modules/proxy.rs`）：Windows `tasklist`、Unix `pgrep -f` 检测，未运行则直接 spawn；Windows 返回 `ERROR_ELEVATION_REQUIRED`（740）时改用 `ShellExecuteExW(runas)`，由系统显示 UAC，其他启动错误不提权重试。前端捕获启动 rejection 后通过 `runtimeToast.error` 写入[通知中心](通知中心.md)，标题本地化，正文保留原始 OS 错误。
- 终端代理状态提示：PTY 创建时 `useGhosttyTerminalSession` 把实际注入的终端代理 URL 登记到 `src/modules/proxy/lib/terminalProxyRegistry.ts`（按 leafId，销毁时移除）。终端代理开启且无需刷新时，状态栏左侧（隐私徽章旁）显示 `src/modules/proxy/components/TerminalProxyBadge.tsx` 绿色胶囊徽章「代理：终端命令已生效」，悬停提示终端命令与 AI 执行的命令都会走代理；右下角代理图标保持原样（图标+计数）。任一存活终端的快照与当前设置不一致时，徽章隐藏，右下角显示琥珀色「刷新终端生效」按钮（`ProxyStatusButton` 用 `useSyncExternalStore` 订阅登记表，点击经 `terminalSessionApi.restartAllSessions` 动态 import 批量 respawn 所有会话），弹层内终端行下方同步显示提示。快照按 URL 比较，开关关了再开（URL 未变）不会误报。
- AI 面板代理提示：`src/modules/ai/components/AiPanel.tsx` 的 `ProxyHints` 在面板头部显示紧凑徽章（脉冲圆点 +「代理中」+ 下拉图标），点击展开**只读**弹层，只展示**已开启**代理的场景及生效后果（不提供开关，开关在状态栏弹层/设置页），失焦自动关闭；两个开关都关闭或代理地址不合法时不显示。AI 命令走代理即时生效，无需刷新终端（`src/modules/ai/tools/shell.ts` 每次执行命令经 `proxyForScenario(usePreferencesStore.getState(), "terminal")` 动态读取偏好）。

## 已知限制

- 终端代理只对新建终端生效，已运行的 Shell 环境不变。
- 仅支持 HTTP 代理（`http://host:port`），不支持 SOCKS/认证信息。
- 自动启动按可执行文件名/路径检测进程，便携版多开场景可能误判为已运行。
- Windows 上要求管理员权限的软件会触发 UAC；用户取消或其他启动失败会进入通知中心，同时保留开发者控制台日志。
- 「刷新终端生效」提示只比较代理 URL（含开关组合结果），代理软件路径等其余设置变化不触发。
