# 标签内搜索

- 最后校验：2026-11-06
- 状态：已覆盖
- 关联约束：[INV-016](../../lore/invariants.md#inv-016)（终端全文查找与块内查找复用同一弹窗）

## 1. 业务需求

Ctrl/Cmd+F 应该只在当前页面有搜索对象时打开搜索框，并落到对的那一个：

- 终端标签：查找终端全文；命令块内查找打开时优先查该块；
- 编辑器标签：交给 CodeMirror 自身查找面板（正则、替换）；
- Git 历史标签：过滤提交列表；
- 设置页：聚焦左侧导航区的设置搜索框，而不是终端搜索框；
- 网页预览：不弹终端搜索框，Ctrl+F 交给预览页面自带的查找功能。

没有搜索对象（如 Markdown 预览、Git 差异）时，顶栏不显示搜索按钮，快捷键也不拦截。

## 2. 入口与调用链

- 快捷键：`src/modules/shortcuts/shortcuts.ts:272` 的 `search.focus`（默认 Mod+F）。
- 分发：`src/modules/shortcuts/lib/useGlobalShortcuts.ts` 捕获后调用 `src/app/App.tsx:1094` 注册的处理器。
- 目标计算：`src/app/App.tsx:1327` 的 `searchTarget` 按当前标签返回 `SearchTarget`（terminal / editor / git-history / null）。
- 终端搜索控制器：`src/app/App.tsx:541` 的 `handleSearchReady` 收集每个叶子的 `TerminalSearchController`，块内查找经 `handleBlockSearch` 覆盖。
- 设置页搜索：`src/settings/settingsSearchFocus.ts` 的 `registerSettingsSearchFocus` / `focusSettingsSearch`，由 `src/settings/components/SettingsSearch.tsx:41` 注册。
- 弹窗 UI：`src/modules/header/SearchInline.tsx`；`src/app/App.tsx:1094` 的处理器在设置页 `return`、在预览页不注册。

```text
Mod+F
  -> useGlobalShortcuts (capture)
  -> handlers["search.focus"]
       settings 标签 -> focusSettingsSearch() -> 左侧 CommandInput.focus/select
       editor   标签 -> EditorPaneHandle.openSearch()
       其他        -> searchInlineRef.focus()
  -> SearchInline.focus (target 为空则直接返回)
  -> 弹窗按 target 调用 TerminalSearchController 或编辑器的 find API
```

## 4. 数据流 / 关键流程

1. `src/app/App.tsx` 在标签或活动叶子变化时刷新 `activeSearchAddon` 与 `activeEditorHandle`（`src/app/App.tsx:532`），避免搜索框持有已注销的控制器。
2. 块内查找打开时 `searchTarget` 优先返回块控制器，并带 `placeholder` 与 `onClose`；关闭弹窗时同步关掉块内查找状态。
3. 处理器在设置标签下直接返回，不再走 `SearchInline`；若设置页尚未挂载，`focusSettingsSearch()` 返回 `false`，按键不产生副作用。
4. 预览标签下 `search.focus` 完全不注册（`src/app/App.tsx:1091`），全局分发不会 `preventDefault`，按键留给 iframe 所在页面。
5. `SearchInline` 在 `target` 为空时渲染 `null`（`src/modules/header/SearchInline.tsx:286`）并关闭已打开的弹窗，因此切换到预览、设置或 Markdown 不会残留终端搜索框。
6. `focus()` 自身也判空（`src/modules/header/SearchInline.tsx:140`），防止调用方绕过按钮渲染直接打开空弹窗。

- 终端搜索控制器契约：`src/modules/terminal/search/TerminalSearchController.ts`。
- HTTP 与第三方接口：无。

## 6. 配置与依赖

- 依赖全局 `TooltipProvider` 与快捷键注册表；搜索弹窗通过 portal 挂在 `document.body`。
- CodeMirror 查找面板使用编辑器自身扩展，不在本功能内重建。
- 无新增偏好键；`search.focus` 可被用户在设置页改键或清空。

## 7. 已知限制与注意事项

- 设置页聚焦依赖设置页已经挂载过；首次打开设置标签前按 Ctrl+F 不会聚焦设置搜索框。
- 预览页只在焦点位于宿主页面（如地址栏、标签栏）时收不到处理；焦点在 iframe 内时按键本来就由 iframe 自己处理。
- 没有搜索对象的标签不显示顶栏搜索按钮，这是有意为之，避免出现点开无反应的搜索框。
- 块内查找关闭时必须同时清理块状态，否则下次 Ctrl+F 会继续指向已关闭的块；由 `handleBlockSearchClose` 负责。
- 新增可搜索的标签类型时，需要同时扩展 `SearchTarget` 与 `src/app/App.tsx` 的 `searchTarget`，并确认 `SearchInline` 的清理逻辑；约束见 INV-016。
