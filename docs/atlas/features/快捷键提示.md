# 快捷键提示

- 最后校验：2026-10-30（`terax-diy`，工作区含本轮未提交改动）
- 状态：开发中
- 关联约束：[INV-012](../../lore/invariants.md#inv-012)

## 1. 业务需求

鼠标悬浮在带快捷键的按钮上时，提示信息应显示该按钮当前生效的快捷键，格式为「提示信息(快捷键)」，例如「设置(Ctrl+,)」。快捷键必须来自快捷键注册表和用户偏好，不能硬编码；用户在设置页改键后，提示应立即同步。

## 2. 入口与调用链

- 响应式令牌：`src/modules/shortcuts/lib/useShortcutTokens.ts:7` 的 `useShortcutTokens`。
- 紧凑文本：`src/modules/shortcuts/lib/useShortcutTokens.ts:14` 的 `useShortcutHint`。
- 统一格式：`src/modules/shortcuts/lib/useShortcutTokens.ts:19` 的 `shortcutHintLabel`。
- 自定义 Tooltip：`src/modules/shortcuts/components/ShortcutTooltip.tsx:23` 的 `ShortcutTooltip`。
- 菜单快捷显示：`src/modules/shortcuts/components/ShortcutTooltip.tsx:42` 的 `ShortcutHint`。
- 导出入口：`src/modules/shortcuts/index.ts`。
- 用户偏好：`src/modules/settings/preferences.ts:48` 的 Zustand store，订阅颜色与快捷键统一来自 `Preferences`。

调用链：

```text
按钮 render
  -> ShortcutTooltip / useShortcutHint(id)
  -> SHORTCUTS[id].defaultBindings 或 user.shortcuts[id]
  -> getBindingTokens(bindings[0]).join("+")
  -> "提示(快捷键)"
```

## 4. 数据流与关键流程

1. `useShortcutTokens` 订阅 `usePreferencesStore.shortcuts`，并查找注册表中该 ID 的默认绑定。
2. 用户存在覆盖时使用覆盖数组，否则使用默认数组；当前只展示第一个绑定。
3. `getBindingTokens` 按平台生成 `Ctrl`、`⌘`、`⇧` 等显示令牌。
4. `useShortcutHint` 用加号连接令牌，`shortcutHintLabel` 生成「提示(快捷键)」。
5. Radix Tooltip 场景由 `ShortcutTooltip` 包装，非 Radix 或原生标题场景直接使用 `useShortcutHint` 与 `shortcutHintLabel`。
6. 设置页写入快捷键后触发偏好更新，所有消费 hook 自动重渲染，无需刷新窗口。

## 5. 对外接口

- 组件：`ShortcutTooltip`，参数为 `id`、`label`、可选的方位与对齐。
- 菜单内文本：`ShortcutHint`，参数为 `ShortcutId`。
- 标题与 placeholder：`shortcutHintLabel(label, hint)`。
- 快捷键事实来源：`src/modules/shortcuts/shortcuts.ts` 的 `ShortcutId` 与 `SHORTCUTS`。
- HTTP 与第三方接口：无。

## 6. 配置与依赖

- 用户偏好：`shortcuts` 映射，键为 `ShortcutId`，值为 `KeyBinding[]`。
- 平台差异：macOS 使用符号令牌，Windows 与 Linux 使用文本令牌。
- 与 i18n：按钮主文案仍由各模块词典提供，括号与快捷键由格式函数追加。
- 无新增环境变量与持久化文件。

## 7. 已知限制与注意事项

- 一个快捷键有多个绑定时，提示只显示第一个绑定。
- 用户清空绑定后只显示提示文案，不显示空括号。
- 原生 `title` 与 Radix Tooltip 不可同时保留，否则会出现两套悬浮提示。
- 新增快捷键按钮时必须使用 `ShortcutId`，禁止把键名直接写进 `title` 或按钮文本；约束见 INV-012。
- Tooltip 组件依赖主窗口的全局 `TooltipProvider`，设置窗口如需使用需补 Provider。
