# 终端路径历史

- 最后校验：2026-11-12（`terax-diy`，含跨工作区路径归一化）
- 状态：可用
- 关联文档：[终端链接打开](终端链接打开.md)（Shift+点击路径 cd 即由链接分流触发）、[状态栏工作区与路径](状态栏工作区与路径.md)（工作区环境判定）

## 1. 业务需求

终端切换目录时，把「刚刚离开的目录」记录下来（浏览器浏览记录模型：`C:\test` 跳到 `C:\test1` 时记录 `C:\test`）。用户可以：

- 按 **Ctrl+E**（终端标签页内生效）打开「最近路径」弹窗，打开即聚焦搜索框，侧边有搜索按钮，回车或点击条目即在当前终端 `cd` 过去；
- 在命令面板输入 **>** 前缀搜索历史路径，选中后同样 cd；
- 在 **设置 → 通用 → 终端 → 路径历史** 修改保留条数（默认 10，可选 5/10/20/50/100）。

历史在 Windows 与 WSL 工作区之间共享，展示与选中时按**当前工作区**归一化（详见第 4 节规则 6）：

- Windows 工作区：统一为 Windows 格式；`/mnt/c/...` 或自定义挂载根（`/etc/wsl.conf` `[automount] root`，如 `/w/`）下的路径折回盘符路径（隐藏挂载前缀），`/home`、`/dev` 等 Linux 专属目录直接隐藏；
- WSL 工作区：统一为 Linux 格式；Windows 盘符路径（`C:\proj`）加上当前发行版的挂载前缀（`/mnt/c/proj`），未配置 `[automount]` 时默认 `/mnt`。

## 2. 入口与调用链

- 历史记录：`src/app/App.tsx` 的 `handleTerminalCwd`——OSC 7 上报新 cwd 时，对比叶子旧 cwd，旧值经 `src/modules/terminal/lib/pathHistory.ts` 的 `recordPathHistory` 去重、封顶后写入偏好。
- 快捷键：`src/modules/shortcuts/shortcuts.ts:210` 的 `terminal.pathHistory`（Ctrl/Cmd+E）；App 的 `shortcutsDisabled` 规定其仅在终端标签页激活，同时终端内停用 `tab.newEditor`（新编辑器默认键改为 Ctrl+Alt+E）。
- 弹窗：`src/modules/terminal/path-history/PathHistoryDialog.tsx:32`，挂载于 `src/app/App.tsx`（CommandPalette 旁）；内部经 `useVisiblePathHistory` 归一化偏好里的历史，选中回调 `handlePathHistoryPick` 对活动终端叶子执行 cd。
- 命令面板：`src/modules/command-palette/lib/mode.ts` 的 `>` 前缀（mode `paths`）；列表在 `src/modules/command-palette/CommandPalette.tsx`，数据来自 App 传入的归一化 `visiblePathHistory`。
- cd 执行：`src/modules/terminal/lib/terminalCd.ts:19` 的 `cdTerminalLeafTo` → `submitToGhosttySession`（自动适配 bracketed paste 并补 `\r`）。

```text
OSC 7 新 cwd -> handleTerminalCwd -> 记录旧 cwd -> 偏好 pathHistory
偏好 pathHistory -> useVisiblePathHistory(当前工作区 + wsl.conf automount root) -> 归一化列表
Ctrl+E / 面板 ">" -> PathHistoryDialog / 面板列表
  -> handlePathHistoryPick -> cdTerminalLeafTo(leafId, 归一化路径)
  -> submitToGhosttySession("cd \"<path>\"") -> OSC 7 回报新 cwd
```

## 4. 数据流与关键规则

1. 偏好键：`pathHistory`（string[]，最新在前）与 `pathHistoryLimit`（默认 10，钳制在 1–100）。
2. 记录时机：仅当叶子的 cwd 实际变化（`previous !== cwd`）时记录旧值；同一路径再次离开时移动到队首而不是重复插入。记录保留 shell 上报的原始格式（Windows 工作区记 Windows 格式，WSL 工作区记 Linux 格式）。
3. 选中历史路径 = 在**当前活动终端标签页的活动叶子**提交 `cd "<path>"`；没有终端标签时弹窗禁选并提示。cd 由 shell 完成，随后走普通 OSC 7 回报，因此该次「离开」也会按规则入史。
4. `buildCdCommand` 去掉路径尾部分隔符（防止转义闭合引号）并转义内嵌双引号；cmd 跨盘符（`/d`）不支持——cmd 不在块集成脚本支持范围内。
5. 路径历史跨标签页、跨 Space 全局共享，随偏好文件持久化。
6. 展示与选中前经 `normalizePathHistoryForEnv` 按当前工作区归一化（同一目录在两种格式下只出现一次，保留最新）：
   - Windows 工作区：Windows 盘符路径原样保留；挂载根（`/etc/wsl.conf` `[automount] root` 与默认 `/mnt/`，取自上次使用的发行版）下的单字母盘符段折回 `X:\...`；其余 Linux 路径（`/home`、`/dev` 等）隐藏；
   - WSL 工作区：Linux 路径原样保留；Windows 盘符路径加当前发行版挂载前缀（未配置 `[automount]` 时 `/mnt`）。
   - 归一化只发生在读取侧；`/mnt/c/x` 与 `C:\x` 在存储中共存是预期行为。

## 6. 已知限制与注意事项

- 记录依赖 OSC 7 目录上报，未启用集成脚本的 shell（如裸 cmd）不会产生历史。
- cd 是向 PTY 提交一条命令：若 shell 正被前台进程占用，命令会进入该进程的 stdin，与用户手敲行为一致。
- 快捷键 Ctrl+E 与「新建编辑器标签页」按上下文互斥（终端内 = 历史弹窗，其余 = 新建编辑器）；两者都可在快捷键设置中改绑。
- automount root 读取自发行版的 `/etc/wsl.conf` 并按发行版缓存：wsl.conf 的修改要 `wsl --shutdown` 后才生效，因此每次应用运行读一次即可。查询由 `useWslAutomountRoot` 的 enabled 门控，只在最近路径弹窗或面板打开时发起，未打开不产生 `wsl.exe` 进程；读取失败（发行版未运行、读取报错）回退 `/mnt/`。配置值不带尾部斜杠（如 `root = /w`）时按 `/w/` 归一。Windows 工作区下自定义挂载根取自 `lastWslDistro` 偏好指向的发行版，其他发行版的自定义根不参与折算。归一化只发生在读取侧、存储保留混合格式，背景见 lore 坑点 [路径历史跨工作区格式混存](../../lore/pitfalls/2026-11-12-路径历史跨工作区格式混存.md)。
