# 状态栏工作区与路径

- 最后校验：2026-11-11
- 状态：已覆盖
- 关联坑点：[终端阻止冒泡导致菜单残留](../../lore/pitfalls/2026-11-11-终端阻止冒泡导致菜单残留.md)

## 1. 业务需求

Windows 用户可在状态栏切换本地工作区与 WSL 发行版，并刷新发行版列表。当前路径以面包屑展示，父目录可直接跳转，当前目录可打开子目录菜单；窄窗口下中间目录收进折叠菜单。工作区环境、当前路径和折叠路径菜单打开后，点击包括终端在内的菜单外区域或按 Escape 都应关闭。

## 2. 入口与调用链

- 状态栏组装：`src/modules/statusbar/StatusBar.tsx:31` 在左侧依次渲染 `WorkspaceEnvSelector` 与 `CwdBreadcrumb`。
- 工作区选择：`src/modules/statusbar/WorkspaceEnvSelector.tsx:41` 在首次打开且未加载时调用 `refreshDistros`，选择结果经 `onSelect` 交给上层切换工作区。
- 路径分段：`src/modules/statusbar/CwdBreadcrumb.tsx:49` 将 cwd 或文件路径转换为面包屑；当前目录菜单打开时经 `list_subdirs` 读取子目录。
- 菜单关闭：`src/lib/useCaptureOutsideDismiss.ts:21` 在菜单打开期间注册 document 捕获阶段 `pointerdown`，菜单内容以外的指针目标触发关闭。

## 4. 数据流与关键流程

1. 工作区菜单打开后读取 `useWorkspaceEnvStore`；无发行版且未加载时调用 Tauri `wsl_list_distros`。
2. 路径菜单使用当前 `WorkspaceEnv` 调用 `list_subdirs`，选择子目录后通过 `onCd` 导航。
3. 菜单打开期间，捕获监听直接引用 Portal 中的 `DropdownMenuContent`；内部点击交给 Radix，外部点击关闭受控菜单。
4. 捕获监听不调用 `preventDefault` 或 `stopPropagation`，终端焦点、选区与后续 Radix 行为保持原样。

## 5. 对外接口

- `WorkspaceEnvSelector.onSelect(env)` 与 `CwdBreadcrumb.onCd(path)` 由 `StatusBar` 透传。
- `useCaptureOutsideDismiss(open, contentRef, onDismiss)` 供其他受控浮层复用。
- 无新增 Tauri command、持久化字段或网络接口。

## 6. 配置与依赖

- 工作区环境选择仅在 Windows 渲染，非 Windows 不订阅工作区环境 store。
- UI 使用现有 Radix `DropdownMenu`，无新增依赖。

## 7. 已知限制与注意事项

- 终端选区控制器会停止指针事件冒泡，不能只依赖 Radix 的冒泡阶段外部关闭监听。
- 共享监听辅助逻辑有单元测试；菜单组件仍无 DOM 测试设施，需手工验证终端点击、菜单内部、Escape、WSL 刷新和窄窗口折叠路径。
