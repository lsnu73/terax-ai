## 1. 业务需求

鼠标多击在终端里选中"有意义的单元"。双击选中光标下的一个词：连续 CJK 块整体选中（不再是单个汉字）；版本号、`foo_bar`、`user@host`、时间、IPv6、`127.0.0.1:8080` 等粘连单元整体选中；斜杠路径（`docs/atlas/changelog.md`、`C:\Users\...`、URL）首次双击只选中光标所在的词段，后续点击沿路径阶梯扩展。三击起阶梯递进：先试引号/括号容器（内部 → 含定界符 → 外层容器），无容器时走路径阶梯（词 → 路径段 → 整条路径），耗尽后回落整行并封顶（不扩展多行块、不触发全选）。

示例：

- 光标在 `tom` 上，文本 `"name:'tom cat 1'"`：双击 `tom` → 击 `tom cat 1` → 击 `'tom cat 1'` → 击 `name:'tom cat 1'` → 击 `"name:'tom cat 1'"` → 击 整行封顶。
- `docs/atlas/changelog.md` 光标在 `changelog`：双击 `changelog` → 击 `changelog.md` → 击整条路径 → 击整行封顶；光标在 `atlas`（段无可扩展词）：双击 `atlas` → 击整条路径。
- `PS C:\Users\wang\Coding\开源仓库\terax-ai>` 光标在 `Users`：双击 `Users` → 击整条路径（含盘符冒号与反斜杠，不含提示符 `>`）。

## 2. 入口与调用链

- 指针事件：`src/modules/terminal/ghostty/selection/TerminalSelectionController.ts:160` 的 `handlePointerDown`（`pointerdown`/`pointermove`/`pointerup` 均挂在该控制器）。
- 多击计数：同文件 `:252` 的 `trackClick`——500ms 内同行相邻（±1 列）的按下累计 `clickCount`（不封顶，WebView 的 `event.detail` 只作下限）。
- 层级解析：同文件 `:234` 的 `resolveLevel`——1 击单字、2 击词；3 击起以双击锚点（`ladderPoint`）先查容器阶梯 `containerRangeAt(point, step)`，未命中再查路径阶梯 `pathRangeAt(point, step)`，都返回 null 则整行。
- 词 token：`src/modules/terminal/ghostty/AdaptedGhosttyTerminalModel.ts:692` 的 `wordRangeAt` 委托纯函数 `wordTokenRangeAt`。
- 容器阶梯：同文件 `:703` 的 `containerRangeAt` 委托 `containerLadderRangeAt`；路径阶梯 `:716` 的 `pathRangeAt` 委托 `pathLadderRangeAt`。
- 选区落盘：控制器经 `selectionForRanges` 生成 `TerminalBufferSelection`，`commitSelection` 写回模型 `setSelection`（native pin，跨输出与 reflow 保持）。

调用链：

```text
pointerdown -> trackClick -> resolveLevel
  ├─ 1 击 -> character（拖拽选字）
  ├─ 2 击 -> model.wordRangeAt -> wordTokenRangeAt
  ├─ >=3 击 -> model.containerRangeAt -> containerLadderRangeAt   （引号/括号）
  │         -> model.pathRangeAt      -> pathLadderRangeAt        （词->段->整路径）
  │            └─ 都 null -> 整行（lineEndColumn）
  └─ 拖拽 -> updateFocus 以同一 mode 计算焦点端
```

## 4. 数据流 / 关键流程

1. 模型按行读出 `cells: string[]`（定长 cols；宽字符第二列是 `""` spacer）。
2. `classifyColumns` 逐列分类：space / word / cjk / glue（`- @ # ? & =`）/ path（`/ \`）/ quote / symbol；`""` 仅在前一格是宽字符时继承其类别（其余是行尾空白填充）。
3. 冒号归并：两侧是十六进制位（时间 `18:30`、IPv6 `fe80::1`、MAC、`host:port`）→ glue；后跟 `/` 或 `\`（盘符 `C:\`、URL scheme `https://`）→ path 分隔符；其余（`error:`、`key:value`）→ 断开。粘连判定优先于断开。
4. 点号归并：两侧是数字（`v1.2.3`、`3.14`、`127.0.0.1`）→ glue；字母间的点（`changelog.md`）断开，交给路径阶梯扩展。
5. `tokenizeColumns` 合并成 token：glue 仅当左右都是 word 时粘连；斜杠/反斜杠是分隔符（断词）；CJK 连续块一个 token，CJK 与 word 交界断开。
6. `containerLadderRangeAt` 扫描引号对（撇号不开容器：前邻是 word 则不算 opener）与括号对（跳过引号内部），按嵌套深度由内向外排链；奇数步选内部、偶数步含定界符。
7. `pathLadderRangeAt` 计算路径段（段内含 glue 与内部点号，CJK/ASCII 交界切断段；`.` 仅在内部或紧邻分隔符时入段，`~` 紧邻分隔符、`%` 后跟十六进制位时入段）与整条路径（段经分隔符链外扩，含悬空的行首 `/` 与行尾 `/`）；第 1 步段不等于词则选段、否则直接选整条路径，第 2 步选整条路径（仅当第 1 步给过段），之后回落整行。

## 5. 对外接口

- `GhosttyTerminalModelApi`（`src/modules/terminal/ghostty/GhosttyTerminalModel.ts:168`）：`wordRangeAt`（必有）、`containerRangeAt`/`pathRangeAt`（可选，返回 `{ start, end } | null`）。
- 无 IPC、无 Rust 侧改动；渲染复用既有选区高亮（uniform）。

## 6. 配置与依赖

- 双击判定窗 500ms、位置容差 ±1 列，硬编码在 `trackClick`。
- 零新增依赖，仅在 pointerdown 时做 O(cols) 扫描，无缓存、无后台工作。

## 7. 已知限制与注意事项

- 选区只用于复制：删除选区、粘贴替换选区未实现（理由与未来重评条件见 [lore 决策](../../lore/decisions/2026-11-16-不做终端选区的删除与粘贴替换.md)）。
- 容器与路径阶梯都只在同一视觉行内匹配；引号跨软换行行（buffer 行）不成对。
- 引号配对是启发式：`don't` 不开容器（撇号前邻 word），但 `'twas` 这类文本可能被误并入邻近单元。
- 点号规则下 `example.com`（无 scheme）双击只选 `example` 或 `com`；带 scheme 时整条 URL 仍可经路径阶梯一步到达。
- `end.Next` 这类无空格句点会被视为段内扩展（`end.Next` 一步选中）。
- 表情符号宽度表按常用块近似；罕见 Unicode 宽字符的 spacer 可能被当成行尾空白，仅影响该字符后缘的选中范围。
- `? & =` 按 glue 处理，因此 `a=1&b=2` 整体选中；`=` 在 shell 赋值场景（`FOO=bar`）同样整体选中。
