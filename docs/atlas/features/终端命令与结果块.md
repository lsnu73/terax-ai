# 终端命令与结果块

- 最后校验：2026-10-30（`terax-diy`，工作区含本轮未提交改动）
- 状态：开发中
- 关联约束：[INV-013](../../lore/invariants.md#inv-013)、[INV-014](../../lore/invariants.md#inv-014)
- 设计原因：[终端统一采用命令与结果块](../../lore/decisions/2026-10-30-终端统一命令与结果块.md)

## 1. 业务需求

普通、隐私、恢复和代理终端统一把用户命令及其执行结果呈现为块，不再存在独立的「命令块」标签类型。用户右键命令、输出或块头区域时，可以重新运行、复制命令、复制输出、复制命令和输出、附加到 AI 对话，或在当前块中查找。

终端存在非空文本选区时，右键继续服务「问问 Terax」选区流程，不得同时打开块菜单。新建隐私终端默认使用 Ctrl/Cmd+Shift+T。Ctrl+R 保留给终端历史命令搜索，设置页不得把它保存为其他全局快捷键。

## 2. 入口与调用链

### 统一块会话

- PTY 初始化：`src/modules/terminal/ghostty/useGhosttyTerminalSession.ts` 始终调用 `ensureGhosttyBlocks(leafId)`，并以 `blocks=true` 打开 PTY。
- 标签状态：`src/modules/tabs/lib/useTabs.ts` 的 `TerminalTab` 不再有 `blocks` 标志或 `newBlockTab`。
- 工作区恢复：`src/modules/spaces/lib/serialize.ts` 不序列化独立块标签标志，旧 JSON 的多余字段自然忽略。
- 共享输入：`src/app/components/WorkspaceInputBar.tsx` 对所有终端叶节点使用块控制器，原生提示符仅作为 `plain` 输入回退。

### 块右键菜单

- 事件分流：`src/modules/terminal/TerminalPane.tsx` 的 `onContextMenuCapture`。
- 坐标换算：右键 `clientY` 经 `ghosttyBlockGeometry` 转为 viewport row，再由 `model.bufferLineAtViewportRow` 转为 buffer line。
- 块命中：`src/modules/terminal/ghostty/GhosttyBlocks.ts` 的 `blockAtLine` 根据 OSC 133 tracked pins 和块范围返回 `PositionedBlock`。
- 菜单操作：`src/modules/terminal/block/BlockContextMenu.tsx` 提供六项操作。
- 块搜索：`TerminalPane` 持有 `blockSearchId`，经 `GhosttyBlockOverlay` 控制原有 `BlockOverlay` SearchBar。

```text
右键终端
  -> 读取 session.getSelection()
  -> 有非空选区：阻止块 ContextMenu，保留选区 Ask AI 流程
  -> 无选区：clientY -> viewport row -> buffer line
  -> GhosttyBlocks.blockAtLine
  -> BlockContextMenu
  -> rerun / clipboard / AI prefill / block search
```

### Ctrl+R 历史搜索

- 保留判定：`src/modules/shortcuts/shortcuts.ts` 的 `isTerminalHistoryBinding`。
- 全局释放：`src/modules/shortcuts/lib/useGlobalShortcuts.ts` 不匹配该绑定，包括旧用户偏好中的绑定。
- 历史弹层：`src/modules/terminal/block/lib/historyPopover.ts` 把 Ctrl+R 绑定到既有 HistoryIndex 查询弹层。
- 设置警告：`src/settings/sections/ShortcutsSection.tsx` 拒绝保存并在当前快捷键行显示中英文冲突警告。

## 4. 数据流与关键流程

1. Shell 集成发出 OSC 133 A/B/C/D，Ghostty parser 创建 tracked pins，块控制器维护有界历史。
2. 每个终端叶节点都挂载 `GhosttyBlockOverlay`，普通、隐私和代理终端不再有行为分支。
3. 右键先检查非空选区。有选区时块菜单不打开；无选区时才进行块命中。
4. 命中命令、输出或块头后，`BlockContextMenu` 读取同一个块控制器，不维护第二份输出副本。
5. 「在命令块中查找」设置受控 `blockSearchId`，沿用有预算、可取消的块搜索。
6. Ctrl+R 在 window 捕获阶段被全局快捷键分发跳过，随后由共享 CodeMirror 输入区打开历史弹层；`plain` 终端则把按键留给 Shell。
7. 设置页录制到 Ctrl+R 时不写 preferences，避免仅靠默认值造成保护漏洞；旧偏好里已有的冲突绑定也显示警告，清除或重置后警告消失。

## 5. 对外接口

- `GhosttyBlocks.blockAtLine(line, cellHeight): PositionedBlock | null`：供右键命中使用。
- `BlockContextMenu`：接收块、prompt 状态、输出读取、重跑、搜索和焦点恢复回调。
- `GhosttyBlockOverlay`：接收 `leafId`、`searchId`、`onCloseSearch`。
- `isTerminalHistoryBinding(binding)`：识别精确的 Ctrl+R，不含 Shift、Alt 或 Meta。
- 无新增 Tauri command、HTTP 接口或持久化格式。

## 6. 配置与依赖

- Shell 集成：OSC 7 与 OSC 133 A/B/C/D；命令边界不能从可见文本猜测。
- 输入模式：`prompt`、`running`、`alt`、`plain`。`plain` 是不支持共享输入时的回退，不是独立终端类型。
- 用户偏好：`shortcuts` 仍可含历史遗留 Ctrl+R，但全局分发层必须忽略它。
- AI 附加：复用独立 AI 窗口 prefill，输出继续经 `capAttachOutput` 截断。

## 7. 已知限制与注意事项

- 没有 OSC 133 边界的输出无法可靠划分命令与结果块，不应通过文本启发式伪造边界。
- 右键空白处或未命中块时不打开块菜单。
- 菜单中的重跑要求完整命令、非运行中状态、可重跑标记以及 prompt ready。
- 本轮按用户要求未运行测试、类型检查、Lint、构建或真实 UI 验证。
