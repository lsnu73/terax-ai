# 终端链接打开

- 最后校验：2026-10-31（`terax-diy`）
- 状态：可用
- 关联文档：[终端路径历史](终端路径历史.md)（Shift+点击路径 cd 后的记录）

## 1. 业务需求

终端输出中的链接按目标类型分流。URL：Ctrl 或 Cmd 加左键在系统浏览器打开；Shift 加左键在内置预览标签页打开。绝对路径（Windows 盘符与多段 POSIX 路径，含 OSC 8 `file://` 超链接）：Ctrl 或 Cmd 加左键在文件管理器中打开（优先第三方文件管理器，Explorer 垫底）；Shift 加左键向当前终端提交 `cd` 切换到该目录。普通左键不触发任何打开。

## 2. 入口与调用链

- 链接检测：`src/modules/terminal/ghostty/core/terminalLinks.ts:36` 的 `detectTerminalLinks` 检测 URL 与绝对路径（三趟正则，路径不覆盖已识别的 URL 区间）；OSC 8 超链接由终端模型直接提供。
- 修饰键判定：`src/modules/terminal/lib/terminalLinks.ts:10` 的 `linkModifierHeld` 接受 Ctrl、Cmd 或 Shift。
- WebGPU 点击：`src/modules/terminal/ghostty/gpu/WebGpuTerminalSurface.ts:839` 到 `:846` 传递点击修饰键。
- WebGL 回退点击：`src/modules/terminal/ghostty/webgl/WebGlTerminalSurface.ts:570` 到 `:577` 传递同一组修饰键。
- 打开分流：`src/modules/terminal/ghostty/useGhosttyTerminalSession.ts` 的 `onOpenLink`——先经 `src/lib/open-path.ts:17` 的 `pathFromLink` 识别文件路径（含 `file://` 转 OS 路径），路径按修饰键分流到 `openPathInFileManager` 或 `src/modules/terminal/lib/terminalCd.ts` 的 `cdTerminalLeafTo`；非路径维持 Shift 预览 / Ctrl 浏览器。
- 回调透传：`src/modules/terminal/TerminalPane.tsx:50`、`src/modules/terminal/TerminalStack.tsx`、`src/app/components/WorkspaceSurface.tsx`。
- 预览打开：`src/app/App.tsx:820` 的 `openPreviewTab`，最终调用 `src/modules/tabs/lib/useTabs.ts:932` 的 `newPreviewTab`。

调用链：

```text
Modifier + 左键
  -> Terminal surface pointerup
  -> onOpenLink(uri, modifiers)
  -> pathFromLink(uri)
     ├─ 路径: Shift -> cdTerminalLeafTo（cd 命令）
     │        Ctrl/Cmd -> open_path_in_file_manager（Rust file_manager 探测）
     └─ URL : Shift 且 http(s) -> App.openPreviewTab
              其余 -> openExternalUrl（系统浏览器）
```

## 4. 数据流与关键流程

1. 鼠标移动并按住修饰键时，终端 surface 命中当前单元格对应的 URL。
2. pointerdown 记录命中的链接，pointerup 要求仍是同一链接，避免拖动或滚屏误触。
3. surface 将 URI 和 Shift、Ctrl、Meta 状态交给会话层。
4. 会话层先用 `pathFromLink` 判定链接是否为文件路径（原始绝对路径或 OSC 8 `file://`）。
5. 路径：Shift 提交 `cd "<path>"`（bracketed paste 适配、尾部多余分隔符剥离）；Ctrl/Cmd 调用 Rust `open_path_in_file_manager`，Windows 上沿用 file_manager 模块的第三方管理器探测链。
6. URL：Shift 且 http(s) 走预览打开回调；其余 `openExternalUrl` 由系统默认浏览器处理。
6. `openPreviewTab` 新建或激活预览标签页，预览页通过既有 `PreviewPane` 加载 URL。

## 5. 对外接口

- 用户操作：Ctrl 或 Cmd 加左键、Shift 加左键。
- 组件契约：终端 surface 的 `onOpenLink(uri, modifiers)`。
- 应用契约：`openPreviewTab(url: string)`。
- HTTP 与第三方接口：无新增。

## 6. 配置与依赖

- 链接识别依赖 Ghostty 模型的 OSC 8 与可见文本 URL 检测。
- 预览打开依赖预览标签页和现有 `PreviewPane`。
- 系统浏览器打开依赖 `@tauri-apps/plugin-opener` 与 `opener` capability。
- 无新增偏好设置项。

## 7. 已知限制与注意事项

- 路径分支先于 URL 分支：路径不参与预览；URL 不参与文件管理器/cd。
- POSIX 路径要求两段以上（如 `/usr/local/bin`），单段 `/etc` 不视为链接，避免误伤 "and/or" 一类文本。
- `open_path_in_file_manager` 要求路径真实存在，文件会打开其父目录；不存在的路径返回错误并仅记录控制台。
- `mailto:` 和其他非 HTTP URL 不使用预览，仍交给系统处理。
- 目标网站可通过 `X-Frame-Options` 或 CSP 拒绝 iframe 嵌入，预览页会显示既有提示条。
- 修改 surface 回调签名时必须同步 WebGPU 和 WebGL 两条路径，否则回退渲染器会出现行为差异。
- Shift 也从终端选择修饰键变为链接修饰键，但只有在指针命中可打开链接时才激活链接动作。
