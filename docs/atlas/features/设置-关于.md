- 最后校验：2026-11-02

## 业务需求

设置窗口的「关于」分区：展示应用名称、标语、版本、构建平台、包标识与许可证，提供指向 GitHub 仓库的源代码链接，以及「检查更新」「在 GitHub 查看」「报告问题」三个操作按钮。检查更新按钮由更新模块驱动，显示检查中/下载中/已是最新等状态与下载进度。

## 入口与调用链

- 设置窗口分区导航 → `src/settings/SettingsView.tsx` 渲染各分区 → `src/settings/sections/AboutSection.tsx:24` `AboutSection` 组件。
- 版本/名称来自 `@tauri-apps/api/app`（`getVersion`/`getName`），平台与架构来自 `@tauri-apps/plugin-os`（`platform`/`arch`）。
- 检查更新按钮调用 `src/modules/updater` 的 `useUpdater`（`src/modules/updater/useUpdater.ts:9`），其 `GITHUB_LATEST_RELEASE` 指向本仓库 Releases 最新版 API。
