## 如何在终端逐列 cells 上实现双击选词这类"选中有意义单元"的交互？

- 首次记录：2026-11-16
- 适用场景：在 ghostty cells 数组（定长 cols、宽字符占两列）上实现选词、拖选扩展、命中高亮等按"有意义单元"取文本的交互；或为终端文本写规则分词器
- 关联功能：[features/终端双击选词.md](features/终端双击选词.md)
- 关联 lore：[decisions/2026-11-16-终端双击选词分词与阶梯规则.md](../lore/decisions/2026-11-16-终端双击选词分词与阶梯规则.md)、[pitfalls/2026-11-16-宽字符spacer与空白填充同为空串.md](../lore/pitfalls/2026-11-16-宽字符spacer与空白填充同为空串.md)

### 目标

双击选中"有意义的单元"（CJK 连块、路径段、版本号、`foo_bar`、引号内容），三击起逐级扩展（引号容器阶梯、路径阶梯），耗尽回落整行封顶；硬约束是零依赖、零缓存、无词典，仅在点击时做 O(cols) 扫描。

### 走过的弯路

| 尝试 | 结果 | 为什么不行 |
|---|---|---|
| 三类字符（space/word/punctuation）同类扩展（旧实现） | 双击中文只选中半个字；`/usr/local/bin`、`v1.2.3` 碎成片段 | CJK 宽字符第二列 spacer（读作 `""`）归入 punctuation 立刻切断扩展；连接符无粘连规则 |
| 照抄需求文档的规则表（PathSep/UrlGlue 永不切断） | `error:` 连冒号一起选中 | 文档规则表与效果示例互相矛盾，且与用户真实期望冲突；示例才是真规范，矛盾处必须逐项问用户 |
| `""` 一律继承前一格的类别 | 词一直延伸到行尾 | 宽字符 spacer 与行尾空白填充同值，按值区分必然二选一出错 |
| 一次性按规则表实现全部行为再交付 | 第二轮才暴露盘符冒号（`PS C:\...`）与字母点号断词的缺失 | 规则边界要靠真实终端输出（提示符路径、git status 路径、URL）逐条暴露，先上真实样本再收敛 |

### 最终有效路径

1. 规则全部收敛到一个纯函数模块 `src/modules/terminal/ghostty/selection/wordSelection.ts`：`classifyColumns`（逐列分类 + spacer 按前格宽度继承 + 冒号/点号 run 的二次归并）→ `tokenizeColumns`（glue 两侧都是 word 才粘连、斜杠一律断词）。模型（`wordRangeAt`）与控制器只做委托。
2. 多击交互用「阶梯」统一建模：双击选词，三击起每击沿阶梯走一步。两条阶梯并列、容器优先：容器阶梯（内部 → 含定界符 → 外层容器）与路径阶梯（词 → 路径段 → 整条路径），耗尽后回落整行并封顶。控制器只存 `clickCount` 与双击锚点，每步向模型可选 API（`containerRangeAt`/`pathRangeAt`）查询，查不到就回落。
3. 与用户对齐行为时，给具体字符串的逐击序列（如 `"name:'tom cat 1'"` 光标在 `tom` 上的六击结果）让用户裁定规则矛盾处，而不是复述抽象规则。
4. 测试矩阵锁定行为：纯函数用例逐条覆盖规则特例（两种 `""`、冒号三态、点号数字/字母、盘符、`~`、撇号不开容器），控制器集成测试走完整点击序列并逐步断言选区；真实解码链路由 WASM 模型测试覆盖。

### 为什么有效

分词与交互解耦：纯函数可脱离 WASM 独立测试，行为由测试矩阵锁定而非代码注释；「阶梯」把任意嵌套或分层结构的选择统一成"每击一步"，新增一类结构只需新增一个 `ladderRangeAt` 纯函数并接入 `resolveLevel` 的查询链，不改动既有阶梯。

### 下次复用要点

- cells 定长 cols、宽字符第二列是 `""`：`""` 仅在前一格是宽字符时才是 spacer，其余是行尾空白填充；必须按前格宽度区分，两种处置各有对应的测试用例。
- 冒号、点号这类多义连接符：先按默认类分类，再按「run + 两侧字符」二次归并（时间/IPv6/盘符/URL 各有判定），不要试图在单字符分类里解决。
- CJK 与 ASCII 交界一律断开：词、路径段、路径结构三处都要切，否则中文散文会粘连进路径。
- 与用户对齐选词行为：给逐击示例序列而非抽象规则；规则表与示例矛盾时以示例为准，并把矛盾逐项抛给用户。
- 新增一类可扩展结构 = 新增一个 `ladderRangeAt` 纯函数 + 模型可选 API + `resolveLevel` 查询链一步接入，零改动既有阶梯。
